品牌識別

讓想法，擁有自己的模樣。

PROJECT / 01

再·栽生

以設計，延續生命。

  • 品牌識別
  • 永續概念

「再·栽生」以圓形花朵、陽光與綠色幾何形，連結生長、自然及重新開始的意象。識別延伸至種植盒，讓標誌不只停留在平面，而成為可以接觸的物件。以清晰親切的視覺語言，邀請人們重新思考日常材料的可能性。

01 / 02

PROJECT / 02

閩南藍衫

以當代語言，回望地方文化。

  • 品牌識別
  • 地方文化

從閩南服飾文化出發，以克制的藍色、重新構成的中文字形與細緻紋樣，建立帶有地方記憶的識別系統。文具應用以留白及清楚層級平衡文化元素，探索傳統如何轉化為今日仍然親切、實用的視覺語言。

01 / 02

PROJECT / 03

造·茶韻

與茶，一場安靜的對話。

  • 品牌識別
  • 茶文化

結合中式窗框、文字結構與茶文化意象，以印章式標誌作為識別核心，再透過棕、紅、綠色延伸品牌節奏。從標誌構成到應用，設計在文化熟悉感與當代清晰度之間取得平衡，保留品茶所帶來的沉靜與餘韻。

01 / 02

PROJECT / 04

閩南春仔花

讓花的線條，成為品牌的語言。

  • 品牌識別
  • 文創設計

從閩南春仔花與纏繞線條出發，以俐落的紅色花形作為識別核心，搭配藍、黃流線細節。紋樣系統在完整花形、局部裁切及連續邊飾之間變化，延伸至文具、卡片與信封，讓清晰的品牌符號與細緻圖案彼此呼應。

PROJECT / 05

大樹藥局

讓關懷，扎根於每個細節。

  • 品牌識別
  • 品牌應用

以承托的雙手與愛心樹葉構成樹形標誌，為大樹藥局建立親切、帶有關懷感的識別語言。綠色、暖金及柔和中性色串連標誌組合、重複紋樣與幾何圖案，延伸至文具、提袋、杯具、工作服及會員卡，探索關懷意象如何在不同日常接觸點維持一致辨識度。

DESIGN — 0203 件作品

文化創意

換一個角度，看見文化。

01 / 04

PROJECT / 06

巴蜀文化絲巾

展開一方，文化的故事。

  • 文化產品
  • 圖案設計

將巴蜀文化意象轉化為可穿戴的圖案，以對稱構圖、動物形態與裝飾幾何，建立遠看鮮明、近看細緻的視覺。三組配色保留同一結構，呈現不同情緒；透過絲巾的摺疊與穿戴，讓文化故事進入日常。

PROJECT / 07

多巴胺販賣所

販賣色彩，也分享快樂。

  • 角色 IP
  • 文創產品

以色彩帶來的愉悅感為起點，建立表情鮮明的角色系列，延伸至匙扣、文具及日常小物。不同應用讓角色擁有各自的舞台，同時以繽紛配色及圖形系統維持辨識度，探索插畫如何形成完整的文創產品家族。

01 / 02

PROJECT / 08

北京文化熊

一個角色，延伸多種相遇。

  • 角色 IP
  • 文創產品

以表情豐富的熊貓與華麗戲曲頭飾，建立北京文化熊的角色世界。紅、藍、金色細節形成鮮明輪廓，不同表情與動作則延伸角色性格。透過角色設定及禮袋、文具、杯具、服飾與配件的模擬應用，探索同一文化角色如何在日常物件中維持辨識度，同時帶來不同互動感受。

DESIGN — 0303 件作品

視覺傳達

PROJECT / 09

打破界線

美，不只一種定義。

  • 宣傳視覺
  • 個人概念創作

這組個人概念創作，以美妝作為自我表達的媒介。人物在連續畫面中逐步轉變，周圍的工具與產品構成敘事線索。透過變化、對比及直接的訊息，探索社交宣傳視覺如何回應外貌與身份的既定想像。本作品並非品牌委託。

PROJECT / 10

海上安全・視覺傳達

讓公共資訊，更容易被看見。

  • 海報與傳單
  • 宣傳設計

以海上安全與公共傳達為主題，將海事圖形、藍色調與資訊層級延伸至橫幅、單張、資料夾及紀念品。面對不同閱讀距離與使用情境，設計兼顧活動辨識度與資訊清晰度，讓公共訊息更容易被接近。

01 / 02

PROJECT / 11

母親節卡片

用一張卡片，說一聲謝謝。

  • 賀卡設計
  • 插畫

以粉色花卉、繡框意象與如線般延伸的連續筆觸，將母親節的感謝心意串連至封面及摺疊內頁。線描手勢增添親切感，書寫區則保留寄語空間。兩張模擬圖呈現卡片不同展開角度，讓裝飾細節與親筆祝福取得平衡，成為可以收藏的小小心意。

DESIGN — 0402 件作品

包裝設計

為日常，包裝一點心思。

PROJECT / 12

日常咖啡

把日常儀式，裝進瓶裡。

  • 包裝設計
  • 咖啡

以瓶裝咖啡作為日常儀式，透過字體及插畫建立各有表情、又彼此連結的標籤系統。透明瓶身與深色咖啡液也參與構圖，讓包裝呈現親切放鬆的氣質，無論在貨架或餐桌上都能被辨認。

PROJECT / 13

一罐風味

從食材，延伸至第一印象。

  • 包裝設計
  • 食物插畫

以食材插畫與暖棕色調建立 XO 醬的包裝語言，讓海鮮圖形傳達內容物，直式字體則形成鮮明節奏。罐身與外盒延續相同線索，在不過度堆疊元素的前提下，讓風味與產品性格於開封前被感知。

DESIGN — 0501 件作品

展覽與活動

讓想法，成為可以走進的空間。

PROJECT / 14

咖啡實驗室

走進一個，關於咖啡的想法。

  • 展覽概念
  • 空間傳達

以陳列、品飲及交流構成探索咖啡的展覽空間。清楚的門頭識別串連展位，食材展示、產品牆與角色裝置建立不同觀看焦點。作為展覽設計概念，作品探索主題如何延伸至標示、物件與參觀體驗，同時照顧遠距辨識及近距互動。
